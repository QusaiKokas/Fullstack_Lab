# DA219B Fullstack Lab

This repository currently contains project structure only.
No application logic has been implemented yet.

## Problem statement
A web app for managing student projects with clear ownership, task status, and progress tracking.

## Planned stack
- Frontend: React + Vite
- Backend: Express.js + Mongoose
- Database: MongoDB Atlas

## Folder structure
- frontend/: React app shell
- backend/: Express API shell
- docs/: ERD and report assets

## Quick start (planned)
1. Copy backend/.env.example to backend/.env and fill values.
2. Install dependencies in root, frontend, and backend.
3. Run one command from root to start frontend and backend.
